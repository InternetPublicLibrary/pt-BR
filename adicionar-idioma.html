Adicionar Seu Idioma

Ajude-nos a tornar a educação acessível a todos traduzindo a IPL para o seu idioma.

Começando

  1. 1
    Junte-se à nossa comunidade
    Apresente-se nas nossas Discussões do GitHub
  2. 2
    Faça fork do repositório
    Crie um fork do repositório do site da IPL
  3. 3
    Crie a pasta do idioma
    Crie uma pasta com o código do seu idioma (ex: es-ES, fr-FR)
  4. 4
    Traduza o conteúdo
    Comece a traduzir páginas do inglês
  5. 5
    Envie um pull request
    Vamos revisar e mesclar suas traduções
