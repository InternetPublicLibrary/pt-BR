A Internet Public Library não tem contas de usuário. A leitura é livre e aberta, sem cadastro, e as contribuições acontecem no GitHub.

Como participar sem conta

  • Sugerir um recurso — abre uma issue pré-preenchida no GitHub.
  • Reportar um problema — links quebrados, informações desatualizadas ou incorretas.
  • Editar páginas no GitHub — toda página tem a aba "Editar", que abre o arquivo de origem.
  • Guia de contribuição — o que aceitamos e como funciona a revisão.

A conta no GitHub só é necessária para contribuir. A IPL não guarda senhas nem dados pessoais.
