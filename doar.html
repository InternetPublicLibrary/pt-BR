Apoie a educação gratuita

As doações online ainda não estão abertas. Você já pode apoiar a Internet Public Library de outras formas.

Como ajudar hoje

  • Sugira recursos confiáveis sobre qualquer tema.
  • Reporte links quebrados ou desatualizados.
  • Ajude a traduzir páginas para o inglês ou para um novo idioma.
  • Dê uma estrela e divulgue o projeto no GitHub.

Quando as doações abrirem, esta página vai explicar como os recursos são usados.
