Perguntas Frequentes

O que é a Internet Public Library?

A IPL é um diretório gratuito e curado de recursos educacionais organizados por categoria. É como uma biblioteca para os melhores materiais de aprendizagem da internet.

Como posso contribuir?

Você pode enviar novos recursos, reportar links quebrados, sugerir melhorias ou ajudar a traduzir conteúdo.

A IPL é realmente gratuita?

Sim! A IPL é completamente gratuita. Somos um projeto de código aberto mantido por voluntários.

Como reportar um problema?

Use nosso formulário de problemas ou abra uma issue no GitHub.
