Como Contribuir com Traduções

1

Faça Fork do Repositório

Comece fazendo fork do nosso repositório GitHub para sua conta.

2

Crie uma Pasta de Idioma

Crie uma nova pasta com o código do seu idioma (ex: es-ES para Espanhol).

3

Traduza o Conteúdo

Copie o conteúdo em inglês e traduza, mantendo a mesma estrutura de arquivos.

4

Envie um Pull Request

Envie suas traduções para revisão. Nossa equipe ajudará com qualquer problema.

Diretrizes de Tradução

  • Use linguagem natural e que soe nativa
  • Mantenha termos técnicos consistentes
  • Não traduza exemplos de código ou URLs
  • Faça perguntas nas discussões do GitHub se tiver dúvidas
